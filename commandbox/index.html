The idea behind CommandBox

A starting point for your own programming language.

CommandBox provides a collection of commands that can be renamed and customized to create a personalized command-based programming environment.

⌘

Command-Based Structure

Begin with predefined commands that serve as entry points to individual batch files and their associated operations.

✎

Customize Your Commands

Rename and modify the command structure to reflect the syntax and naming conventions of your own programming language.

⌘

Experiment and Build

Create your own collection of commands, test their behaviour, identify errors and improve your programming environment.

Getting started

From a collection of commands to your own language.

The original CommandBox 1.0.0 guide describes a straightforward five-step customization process.

STEP 01

Prepare Your Files

Create ten batch files that will serve as the foundation of your command structure.

STEP 02

Rename the Files

Give the files names ranging from project0.bat to project9.bat.

STEP 03

Build Your Software

Create a software interface containing commands from command0 to command9.

STEP 04

Test and Improve

Run your software, identify unexpected behaviour and correct errors in your files.

STEP 05

Make It Yours

Rename the commands according to your desired language conventions.

Understand the mechanism

Simple commands. Custom possibilities.

In the first edition, CommandBox uses a simple command-to-batch-file relationship.

For example, invoking command0 opens project0.bat, while command1 opens project1.bat.

By modifying the underlying batch files and command names, you can experiment with your own command conventions.

Frequently asked questions

Things worth knowing.

A few useful answers before exploring CommandBox.

CommandBox is a collection of commands designed to provide a starting point for creating and customizing a command-based programming language.
The CommandBox 1.0.0 guide explains how to rename and customize its commands and underlying batch files to develop your own command conventions. Building a complete programming language will require additional design and implementation work.
In the first edition, these commands open their corresponding batch files, from project0.bat through project9.bat.
The published itch.io listings specify minimum purchase prices of $10, $20 and $30 for versions 1.0.0, 2.0.0 and 3.0.0 respectively. Check each listing for its current purchasing conditions.
All three editions are available through their respective itch.io product pages. Select your preferred edition in the collection above.
The documented first-edition functionality is based on command-to-batch-file execution. A compiler, parser or complete programming language runtime is not established by the available product documentation.
